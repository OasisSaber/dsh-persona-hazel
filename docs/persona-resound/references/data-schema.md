# 数据架构：人格数据的分层职责与设计铁律

一个角色 = 一组各司其职的数据文件。**核心原则：每层管一件事，出问题能定位到具体层。** 分层去重是这套架构的根基——同一件事被注入 2-4 遍时，你会不知道往哪层根治。

## 目录结构（4 个子目录）

```
persona/
├── core/      ① 核心人设（她是谁，always-on）→ system_prompt + traits + styles
├── behavior/  ② 行为（怎么反应，触发命中才带）→ behaviors
├── speech/    ③ 说话（怎么说，few-shot 风格）→ voice_samples + phrases
└── world/     ④ 世界/记忆（经历/懂什么）→ terms + core_stories + preferences
```

**分目录的根据 = 消息组装的先后**：core（她是谁）永远在，behavior/speech/world 按当前消息情境检索命中才注入。

## 分层职责表

| 层 | 子目录 | 职责 | 设计铁律 |
|---|---|---|---|
| `system_prompt` | core/ | 她是谁 + 底线 + 身份机制 | 只放**不可压缩**的：心理人格 / 身份分层 / 沟通底线 / 自我称呼 / 括号纪律 |
| `traits` | core/ | 性格基底 | 行为化性格描述 + 事件证据；**不贴"-主义者"临床标签** |
| `styles` | core/ | 语言特征清单 | 具体句式示范；下沉 system_prompt 没细说的风格细则 |
| `behaviors` | behavior/ | 情境反应 + 行为边界 | 触发 → 响应 + **真人原话示范**（few-shot）；一条一情境 |
| `voice_samples` | speech/ | 说话示范（few-shot） | 大量真实对话对（user + reply）；**唯一的风格示范层** |
| `phrases` | speech/ | 措辞指纹 | 同一意思 → 她真实说过的原话；只锚定高频稳定说法 |
| `terms` | world/ | 世界名词（lorebook） | 核心词 always 注入 + 命中注入；可带 reaction（被提到时态度） |
| `core_stories` | world/ | 核心记忆 | 印象最深的结晶；低阈值高浮现 |
| 梗库（LEGENDARY） | core.py | 固定回答 | 关键词粗筛 + **LLM 语境确认**双路由（防误触发） |
| `corpus` | data/ | 背景记忆 RAG | 场景化陈述；仅相关时提及，不参与风格 |
| `preferences` | world/ | 偏好事实 | 一条一话题；命中才注入；与语料/记忆冲突时以偏好为准 |

## 设计铁律

### 一个词只进一层

「懂」进 terms / 「忆」进 core_stories / 「答」进梗库——一个词只进一层，防止重复注入。

- 名词/世界设定 → terms（"绿冻是粉丝统称"）
- 印象最深的经历 → core_stories（"考了222名"）
- 固定回答/口语梗 → 梗库（"绿冻永远是第二选择"）

### behaviors：触发要具体，示范要真人原话

- **trigger 描述具体情境**（"粉丝质疑灰泽满——'你是不是在敷衍我'这类话"），不要泛泛（"在互动中需要推进对话时"）。
- **samples 用真人原话示范**（粉丝说 X → 她回 Y），模型照着学腔调，不自己发明。
- 触发-响应是"指令 + 示范"，不是纯指令。

### voice_samples：风格示范，但防内容抄袭

- 样本注入是 few-shot，模型会抄**内容**（人物/礼物/事件）不只学语气。提示标签必须写明"只学语气断句自称，不要套用示例里的具体内容"。
- 样本 user 描述精确限定触发语境，避免误命中。
- 样本分 short/long 档，注入优先 short（控制回复长度）。

### terms：单字/别名要防误触发

- 子串匹配会误伤（单字"区"撞"小区/地区/区服"）。用 **pattern 正则**精确命中（如 `满区|(这么|太|好|很|真…)\s*区`）区分形容词用法与普通名词。
- 定义控制在 ~60 字（够理解 + 带态度），太长占上下文、过度锚定。

### core_stories：作品原文必须真入库

- 如果角色有作品（小说/歌/画），"直播/作品里念过开头"≠"原文在数据里"。**要能逐字引用，必须把原文真入库**，否则模型只能梗概，被要求"念一下"时会编造。

### 提示词与数据的分工

- **提示词不放具体台词例句**——带引号的原话放提示词 = "点名口癖 → 每条都加"。
- 例句下沉到 behaviors / phrases / voice_samples（条件注入 + 真人原话）。
- **确定性兜底只在模型默认习惯压不住时才上**（如括号、省略号、第三人称自指的 clean 后处理）。

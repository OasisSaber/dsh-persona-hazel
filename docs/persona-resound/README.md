# Persona Resound · 从真人素材忠实还原一个人的说话方式

> 一个把「让 LLM 忠实还原一个人的说话方式」做成工程的方法论技能包（只还原既有的人，不原创设计）。
> 源自真实项目 [Hzm-AI-Bot](https://github.com/MureasAm/Hzm-AI-Bot)（灰泽满 · 虚拟主播角色一致性对话系统）的数周迭代经验。

**核心信念：角色的像与不像，不取决于模型多聪明，而取决于数据蒸馏、检索、记忆、评测这套体系怎么建。**

## 这是什么

一个可复用的 **Claude Code 技能（skill）**，包含两部分：

1. **`template/` —— 可复制的项目脚手架**：一个能跑的角色 bot 框架（去掉了具体角色内容），含运行时框架代码（检索/记忆/感知/清洗全参数化）+ 蒸馏工具 + 人格数据空模板。填好角色配置 + 人格数据就能跑。
2. **方法论**：核心原则（8 条）+ 数据架构 + 蒸馏管线 + 检索架构 + 嵌入边界 + 评测闭环 + 踩坑清单。

- **核心原则**：样本 > 规则、素材层解决、行为 > 标签、提示词不放台词……（8 条，决定成败）
- **数据架构**：一个人格 = 一组各司其职的数据层（system_prompt / behaviors / voice_samples / phrases / terms / core_stories / corpus / 梗库），每层管一件事
- **蒸馏管线**：素材筛选 → 转聊天 → 挖措辞 → 生成陈述 → 向量化 → 人工审批
- **检索架构**：多路检索 + RRF 融合 + 预算截断，以及**嵌入的边界**（问句 vs 陈述鸿沟 / 句式聚团 / 指代性消息 / 纯情绪消息）
- **评测闭环**：检索评测（hit rate@K）+ 人格一致性评测（匿名化）
- **踩坑清单**：每一条都是真金白银踩出来的

## 为什么值得看

- 这不是"一个聊天机器人"的教程，而是**角色一致性这个开放问题的工程答卷**——一个不靠模型微调、纯靠数据 + 检索 + 评测就能做到很高还原度的路线。
- 方法全部来自**真实项目的实测**，不是理论推演。每一条原则都标注了"违反它会付出什么代价"。
- 内含大量**教科书没有、踩坑才有的洞察**：embedding 按句式聚团不认意图、问句与陈述式嵌入的鸿沟、模型默认习惯提示词管不住要靠后处理……

## 快速开始

### 作为 Claude Code 技能使用

```bash
# 克隆本仓库
git clone https://github.com/<your>/persona-resound-skill.git

# 安装为技能：把 persona-resound 目录放进 skills 目录
# Unix/macOS:  ln -s <克隆路径>/persona-resound ~/.claude/skills/persona-resound
# Windows:     mklink /D %USERPROFILE%\.claude\skills\persona-resound <克隆路径>\persona-resound
#              （或直接把目录复制过去）
```

之后在 Claude Code 里说"用 persona-resound 从这批素材构建一个角色 bot"，技能会引导你走完整套方法论。

## 方法论速览

1. **样本 > 规则**：真实对话示范"怎么说话"，比规则规定有效得多
2. **素材层解决，别用提示词打补丁**：措辞/括号/重复问题从素材层根治
3. **原始素材 ≠ 聊天格式**：必须转格式（分离转述/回答、切分压缩）
4. **先筛选后分析**：判噪声，只提炼高质量话轮
5. **行为 > 标签**：写"在什么情境怎么反应"，不贴临床标签
6. **提示词不放具体台词**：例句下沉到行为/措辞/样本层
7. **确定性兜底只在模型默认习惯压不住时才上**：后处理 clean
8. **每步产物先展示审批**：不一次性跑完流水线
